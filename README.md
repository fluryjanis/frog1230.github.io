# Frog1230 Portfolio

Welcome to my personal developer portfolio.

I build **local-first, privacy-focused software**, including browser extensions, desktop utilities, and experimental tools designed to solve specific problems without unnecessary cloud infrastructure.

**Live site:** [fluryjanis.github.io/frog1230.github.io](https://fluryjanis.github.io/frog1230.github.io/)

## Featured Projects

### [Research Wheel](https://fluryjanis.github.io/ResearchWheel/)

A research-focused browser extension that puts citations, source searching, quote clipping, and research notes behind a simple middle-click radial menu.

* **Links:** [Website](https://fluryjanis.github.io/ResearchWheel/) | [Firefox Add-on](https://addons.mozilla.org/en-US/firefox/addon/researchwheel/) | [GitHub Repo](https://github.com/fluryjanis/ResearchWheel) | [itch.io](https://frog1230.itch.io/researchwheel)

### [MindShield](https://fluryjanis.github.io/Mind-Shield/)

A privacy-first browser extension that adds a brief reflection pause when you appear to be unnecessarily relying on conversational AI.

* **Links:** [Website](https://fluryjanis.github.io/Mind-Shield/) | [GitHub Repo](https://github.com/fluryjanis/Mind-Shield) | [Firefox Repository](https://github.com/fluryjanis/Mind-Shield-Firefox) | [itch.io](https://frog1230.itch.io/mind-shield)

### [Content Chef](https://frog1230.itch.io/content-chef)

A privacy-first local browser extension designed to filter and curate YouTube video recommendations.

* **Links:** [itch.io](https://frog1230.itch.io/content-chef) | [Firefox Add-on](https://addons.mozilla.org/en-US/firefox/addon/content-chef/) | [GitHub Repo](https://github.com/fluryjanis/Content-Chef)

### [Remind Me](https://frog1230.itch.io/remind-me)

A keyboard-driven 24-hour desktop planner and calendar designed for rapid scheduling.

* **Links:** [itch.io](https://frog1230.itch.io/remind-me)

### [Your Pomodoro](https://frog1230.itch.io/your-pomodoro)

A standalone, modular Pomodoro timer utility derived from the Remind Me planner ecosystem.

* **Links:** [itch.io](https://frog1230.itch.io/your-pomodoro) | [GitHub Repo](https://github.com/fluryjanis/Your-Pomodoro)
